# 无界 · Beauty Beyond

欧莱雅美妆科技黑客松「无界体验家」赛道初步交互 Demo。参赛概念，非欧莱雅官方产品。

**产品主线：安心对话 → 个性化建议 → 照片试色 → 文字／语音反馈 → 按需真人协助。**

视觉以用户提供的宣传图为参考：深紫色背景、细流线、发光环、浅紫色文字与按钮。内容采用尊重自主选择、不作外貌评分的表达。

## 三分钟演示

1. 首页点击「体验 3 分钟演示」。
2. 在「安心对话」选体验方式，再点「有点不敢开始」或「把颜色说给我听」。切换场景、妆感，观察建议变化。
3. 进入「无界试妆」，切换四款色彩、调整浓度、对比原图，点击「听听试色描述」。
4. 点击「恢复示例」可对 AI 示例人像执行真实的本机人脸关键点定位；也可选自己的照片或拍照。首次加载模型可能稍慢。
5. 打开分步指引，或保存试色卡。
6. 在「温暖同行」选择帮助类型与时间，查看模拟安排，然后完成演示。

需要大字、高对比、自动朗读或减少动态时，点击右上角「无障碍」。

## 本次需求覆盖与能力边界

| 核心需求 | 本次实现 |
| --- | --- |
| 聚焦 1–2 类核心人群 | 视障／手部不便，以及美妆初学者／容貌焦虑；提供三种可选择的体验方式 |
| 没有评判的陪伴 | 对话、情绪安慰与安全边界采用清楚标注的预设情景；没有接入大语言模型 |
| 个性化匹配 | 根据用户自己选择的场景、妆感匹配示例色彩；不分析性别、年龄或肤色 |
| 口红上色 | Canvas 上色；自选照片通过 MediaPipe Face Landmarker 在浏览器内定位唇部；初始示例有预设唇区 |
| AR 能力 | 本次为照片试色，不是摄像头实时 AR；实时跟踪留待后续接入 |
| 语音输入与朗读 | 使用浏览器 SpeechRecognition / SpeechSynthesis；识别结果先填入输入框，由用户确认后发送 |
| 图生文反馈 | 本次为色彩、浓度的模板化描述，不伪装为对个人照片的视觉理解；尚未接入视觉语言模型 |
| 无障碍 | 语义控件、键盘导航、跳过导航、页面焦点、对话 live region、原生模态框焦点管理、可读文字等价内容、大字、高对比、减少动态与语速设置 |
| 人机协作 | 志愿者协助、专业支持、机构网络构想；预约仅本页模拟，不收集联系方式或发送请求 |
| 未来人群 | 男性／不受性别标签限制的推荐、长者、疤痕相关专业支持在演示说明中列出 |

完整的免手操作、真实多模态模型、实时 AR 与真实机构预约尚未实现。浏览器语音能力因设备、语言包和权限而异；不能保证所有浏览器都可用。

## 本地运行

无需安装依赖或构建。需要 Node.js 运行检查，Python 启动静态服务器：

```sh
npm test
python -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。不能直接双击 HTML，ES 模块与模型资源需要 HTTP 服务。GitHub Pages 发布分支为 `main`，目录为仓库根目录。

## 数据与权限

- 照片、对话和模拟安排只保存在当前页面内存，不上传、不写入数据库，刷新后清除。
- 只在 localStorage 中保存无障碍偏好。
- 语音输入由浏览器提供，可能把音频交给浏览器供应商的语音服务；用户主动启用并授权后才开始。
- 摄像头只在点击「拍摄照片」后申请权限，关窗或离开页面即停止。
- 试色卡只在用户点击保存后生成到本地下载目录。
- 模型与运行文件均同源托管，不需要第三方 CDN；静态托管服务仍会收到正常的网站资源请求。
- 不放置 API 密钥、真实联系方式、用户资料、原始需求聊天截图或后台凭据。

## 技术与资产来源

- 原生 HTML / CSS / JavaScript，无应用框架或构建依赖。
- `assets/vision/`：`@mediapipe/tasks-vision` 0.10.18，Apache-2.0；本机面部关键点识别，不进行身份识别。
- Face Landmarker 模型：Google MediaPipe float16/1，详见 `THIRD_PARTY_NOTICES.md`。
- `assets/portrait.png`：使用内置 ImageGen 生成的虚构成年人像，不是实际用户或真实代言人。提示词见 `ASSET_PROMPT.txt`。
- 活动链接来自用户：[活动介绍](https://mp.weixin.qq.com/s/HsYcUikzxRQGulak0ZAnvw?scene=1)。原文访问受限，本 Demo 的范围依据用户提供的宣传图与方案截图，不对比赛规则作额外断言。

## 正式版接入点

用服务端模型接口替换 `core.mjs` 的 `replyFor()`，并保持不在前端放置密钥；使用明确同意流程接入视觉语言模型；扩展 `locateFace()` 为视频帧跟踪；预约对接经过核验的合作机构，增加服务核验、同意与取消流程。正式无障碍验收需邀请目标用户参与测试。
